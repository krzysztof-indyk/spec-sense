# Third-party notices

SpecSense is an **unofficial, independent** preset for GitHub Spec Kit. It adopts
an interactive workflow inspired by SDDW. Neither upstream project endorses
or maintains SpecSense.

SpecSense distributes wrappers intended to be composed at installation time
with upstream Spec Kit commands (`{CORE_TEMPLATE}`); it does not bundle
Spec Kit's command templates or SDDW's original command files.
